# Spacematrix Ankara: Keçiören pilotu

Topografya, dere yatakları ve yoğunlaşma, 2002 → 2026. Etkileşimli Spacematrix grafikleri ve 3B zamansal model.

**Site:** https://corrugatedworks.github.io/spacematrix-ankara/

Devam eden akademik çalışmanın ara sonuçlarıdır; alıntı ve yeniden kullanım için yazarlarla iletişime geçiniz. © 2026, tüm hakları saklıdır.

Veri kaynakları: Overture Maps (OSM ODbL, Microsoft CDLA-Permissive), TKGM, Google Earth ve Esri Wayback yıl kesitleri, 1/1000 hâlihazır nokta kotları, Copernicus GLO-30, USGS Hexagon 1973.
